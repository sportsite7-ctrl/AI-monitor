# AI Monitor ⚡

Легкий, швидкий та автономний сайт-радар для відстеження свіжих новин і релізів у сфері штучного інтелекту.

Працює повністю на стороні клієнта та оптимізований для безкоштовного хостингу на **GitHub Pages** — без баз даних, без платних API-ключів та без складних налаштувань.

---

## 🌟 Можливості

- **Миттєве завантаження**: під час першого відкриття відразу відображає кешовану стрічку `news.json` без затримок та білого екрана.
- **Оновлення в реальному часі**: кнопка **«Оновити зараз»** опитує відкриті RSS-джерела прямо з браузера (через публічні проксі та прямі API).
- **Стійкість до збоїв**: якщо одне з джерел тимчасово недоступне, стрічка не ламається — відображаються інші джерела з акуратним сповіщенням.
- **Інтелектуальний фільтр «Важливе»**: автоматично відбирає ключові події, релізи та прориви (`GPT`, `Claude`, `Gemini`, `release`, `open-source`, `model`, `breakthrough`, `deepseek`, `o1/o3`, `agent`).
- **Швидкий пошук та фільтрація**: за ключовими словами в заголовках та анонсах, а також за джерелами (`OpenAI`, `TechCrunch`, `The Verge`, `Hugging Face`, `Hacker News`, `MIT Tech Review`).
- **Фонове оновлення через GitHub Actions**: резервний легкий workflow (`.github/workflows/update.yml`) кожні 3 години запускає `scripts/update_feed.py` та оновлює `news.json`.
- **Сучасний адаптивний UI**: мінімалістична темна тема, скляний ефект (glassmorphism), відносний час («15 хв. тому»), акуратні картки.

---

## 🛠 Стек технологій

- **Фронтенд**: HTML5, CSS3, чистий Vanilla JavaScript (`index.html`, `style.css`, `app.js`).
- **Скрипт синхронізації**: Python 3 (лише стандартні модулі `urllib.request` та `xml.etree.ElementTree`).
- **Автоматизація**: GitHub Actions (cron кожні 3 години).

---

## 🚀 Як увімкнути GitHub Pages

1. Перейдіть до налаштувань репозиторію: `Settings` &rarr; `Pages`.
2. У блоці **Build and deployment**:
   - **Source**: оберіть `Deploy from a branch`.
   - **Branch**: оберіть `main`, папку `/ (root)` та натисніть **Save**.
3. За 1-2 хвилини ваш монітор буде доступний за адресою:
   `https://sportsite7-ctrl.github.io/AI-monitor/`

## 💻 Локальний запуск

```bash
# Оновити стрічку новин локально
python scripts/update_feed.py

# Запустити локальний сервер
python -m http.server 8080
```

Відкрийте у браузері: `http://localhost:8080`
