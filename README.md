# AI Monitor ⚡

Лёгкий, быстрый и автономный сайт-радар для отслеживания свежих новостей и релизов в сфере искусственного интеллекта.

Работает полностью на стороне клиента и оптимизирован для бесплатного хостинга на **GitHub Pages** — без баз данных, без платных API-ключей и без сложной настройки.

---

## 🌟 Возможности

- **Мгновенная загрузка**: при первом открытии сразу отображает кэшированную ленту `news.json` без задержек и белого экрана.
- **Обновление в реальном времени**: кнопка **«Обновить сейчас»** опрашивает открытые RSS-источники прямо из браузера (через публичные прокси и прямые API).
- **Отказоустойчивость**: если один из источников временно недоступен, лента не ломается — отображаются остальные источники с аккуратным уведомлением.
- **Интеллектуальный фильтр «Важное»**: автоматически отбирает ключевые события, релизы и прорывы (`GPT`, `Claude`, `Gemini`, `release`, `open-source`, `model`, `breakthrough`, `deepseek`, `o1/o3`, `agent`).
- **Быстрый поиск и фильтрация**: по ключевым словам в заголовках и анонсах, а также по источникам (`OpenAI`, `TechCrunch`, `The Verge`, `Hugging Face`, `Hacker News`, `MIT Tech Review`).
- **Фоновое обновление через GitHub Actions**: резервный легковесный workflow (`.github/workflows/update.yml`) раз в 3 часа запускает `scripts/update_feed.py` и обновляет `news.json`.
- **Современный адаптивный UI**: минималистичная тёмная тема, стеклянный эффект (glassmorphism), относительное время («15 мин. назад»), аккуратные карточки.

---

## 🛠 Стек технологий

- **Фронтенд**: HTML5, CSS3, чистый Vanilla JavaScript (`index.html`, `style.css`, `app.js`).
- **Скрипт синхронизации**: Python 3 (только стандартные модули `urllib.request` и `xml.etree.ElementTree`).
- **Автоматизация**: GitHub Actions (cron раз в 3 часа).

---

## 🚀 Как включить GitHub Pages

1. Перейдите в настройки репозитория: `Settings` &rarr; `Pages`.
2. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`.
   - **Branch**: выберите `main`, папку `/ (root)` и нажмите **Save**.
3. Через 1-2 минуты ваш монитор будет доступен по адресу:
   `https://sportsite7-ctrl.github.io/AI-monitor/`

---

## 💻 Локальный запуск

```bash
# Обновить ленту новостей локально
python scripts/update_feed.py

# Запустить локальный сервер
python -m http.server 8080
```

Откройте в браузере: `http://localhost:8080`
